# 智能体用户使用说明

> 本说明写给**使用软件的人**。软件已经装好，接下来用 **AI 智能体**（豆包、WorkBuddy、DeepSeekHarness 等）帮你批量盖章、加水印，你不用自己点软件界面。
>
> 按下面三步完成准备工作后，就可以开始第一次对话，之后一切由智能体引导你完成。

---

## 第一步：准备工作（只需做一次）

1. **运行一次软件**：双击软件主程序（EXE 文件名以「文件批量盖章与水印工具」开头），等软件窗口正常打开后关闭它。程序会自动在软件目录生成运行所需的文件，其中包括「运行组件\智能体调用\」下的《智能体调用手册.md》和技能包文件夹「file-stamp-watermark」。
2. **导入印章**（只做盖章任务时需要）：打开软件，在左侧「印章参数」→「选择印章」中导入印章图片，然后关闭软件。之后智能体盖章时，软件会自动从印章库加载这枚章，无需在对话里再传印章图片。

> **注意**：软件**默认不携带任何印章**，需要盖章时请务必先按第 2 步导入自己的公章。
>
> **提示**：只做**加水印**、不盖章的话，第 2 条可以跳过。

---

## 第二步：把软件文件夹交给智能体

在智能体的工作模式里（豆包叫"指定项目文件夹"、WorkBuddy 叫"挂载工作区"、DeepSeekHarness 叫"加载到项目内"，意思一样），新建一个任务，把**整个软件文件夹**指定为工作目录/项目文件夹，让智能体能看到并读取它。

---

## 第三步：发送开场白，开始对话

复制下面这段文字发给智能体：

```
我把文件批量盖章与水印工具软件文件夹放到你的工作区了。请先读取软件文件夹里《运行组件\智能体调用\智能体调用手册.md》，了解本软件支持的任务，然后按手册流程引导我完成本次任务。
```

发送后，智能体会读取《智能体调用手册.md》，判断技能包能否加载：
- **技能包可加载** → 智能体向你说明两种工作方式并请你选择：**A 直接按调用手册工作（不加载技能包）／ B 加载技能包后按技能包工作**——选 A 或 B 即可；
- **技能包不可加载（含版本不一致）** → 智能体会如实告诉你只能选 A（直接按调用手册工作），并告知技能包所在位置（`运行组件\智能体调用\file-stamp-watermark\`）——你可以自己想办法安装（如让智能体检查并调整该文件夹内容、按平台要求放入技能目录）；若因软件升级导致版本不一致，**重新运行一次软件即可自动更新技能包**，装好后下次对话即可选 B。

选定工作方式后，智能体会引导你完成本次任务：它问你什么你答什么，处理结果和输出文件位置它会告诉你。
