# 任务字段说明与默认值（task-spec）

> 本文件是 4 类任务 JSON 字段的最终执行口径。所有参数含义与默认值以本文件为准，**智能体不可发明新规则**。模板位于 `assets/`，从模板出发修改，另存新文件后执行。

## 一、4 类任务一览

| 任务类型 | 能力 | 必填字段 |
|---|---|---|
| `pdf-stamp` | 文件夹内所有 PDF 全部盖章（可加骑缝章、可指定页范围） | `input`、`stamp.image` |
| `pdf-watermark` | 文件夹内所有 PDF 加文字水印 | `input`、`watermark.text` |
| `pdf-text-stamp` | 按指定文字在 PDF 中定位盖章 | `input`、`stamp.image`、`textStamp.keyword` |
| `img-watermark` | 图片文件夹内所有图片加文字水印 | `input`、`watermark.text` |

**水印自动选择**：用户只提供文件夹时，智能体读取文件夹内容自动选择 `pdf-watermark`（只有 PDF）或 `img-watermark`（只有图片）；文件夹同时含 PDF 与图片 → 询问用户三选一（1 只处理 PDF / 2 只处理图片 / 3 全部处理）；既无 PDF 也无图片 → 提示用户重新提供文件夹。

## 二、必改字段清单（不改的后果）

| 任务类型 | 必改字段 | 不改的后果 |
|---|---|---|
| `pdf-stamp` | `input`、`stamp.image` | 印章路径是占位 → 报错"印章图片不存在"，退出码 1 |
| `pdf-watermark` | `input`、`watermark.text` | 水印文字按默认"内部资料"输出，可能不符合用户要求 |
| `pdf-text-stamp` | `input`、`stamp.image`、`textStamp.keyword` | 印章路径是占位 → 报错；关键词不改 → 找不到文字、输出 0 个章但仍显示成功 |
| `img-watermark` | `input`、`watermark.text` | 水印文字按默认"内部资料"输出，可能不符合用户要求 |

模板顶层带 `_说明` 字段（软件解析时自动忽略），每次调用前按 `_说明` 核对必改项。

## 三、默认值总表（用户回复"默认"时按此执行）

| 项目 | 默认值 |
|---|---|
| 盖哪些页 | 全部页 |
| 盖章位置 | 居中（X/Y 50%） |
| 骑缝章 | 不开启；开启时默认 类型=全部页、位置=右、位置百分比 50%（类型可选 全部页/奇数页/偶数页，位置可选 上/下/左/右，百分比 1-100%）；单页 PDF 无需骑缝章 |
| 随机角度位移 | 不开启；开启默认 旋转 45°、横向位移 10mm、纵向位移 10mm |
| 盖章渲染 | 不开启；开启默认 浓淡不均/径向压印/局部露白/内部斑点 15、斑点大小 5、渐变过渡 10、整体色偏 0 |
| 水印透明度 | 30% |
| 水印旋转 | 30° |
| 水印字号 | `fsToS=0.08`（页面/图片短边 8%，横竖页字号一致） |
| 输出命名 | `已处理V` + 数字递增（1、2、3…） |
| 输出位置 | 各源文件夹内 `已处理\` 子目录（源文件永不覆盖） |
| 输出清晰度 | 150 dpi |

## 四、字段说明（模板中出现的全部字段）

### stamp（印章）

- `image`：印章图片绝对路径（必填）。
- `sizeMm`：印章边长（毫米）。**不填时按软件中该章已配置参数**；填写才覆盖（避免模板默认值覆盖用户界面设置）。
- `rotation`：旋转角度。不填时按该章已配置参数；填写才覆盖。
- `opacity`：不透明度 0-100。不填时按该章已配置参数；填写才覆盖。
- `randomParams`：是否开启**随机角度位移**（false/true，默认 false）。
- `randomRotation`：开启时随机旋转角度范围（默认 45）。
- `randomOffsetXMm` / `randomOffsetYMm`：开启时随机横向/纵向位移范围（mm，默认 10/10）。
- `textureQuality`：是否开启**盖章渲染**（false/true，默认 false）。
- `textureBrightness` / `textureRadial` / `textureWhite` / `textureSpot`：浓淡不均/径向压印/局部露白/内部斑点上限（开启时默认 15）。
- `textureBlob`：斑点大小上限（默认 5）。
- `textureGradient`：渐变过渡上限（默认 10）。
- `textureCast`：整体色偏上限（默认 0）。
- `texturePresetIndex`：渲染方案（0 自定义，1-4 方案N）。
- `seam.enabled`：是否加骑缝章（false=不加；true=加，类型见下）。
- `seam.type`：`全部页`（每页都盖，默认）/`奇数页`（只盖 1、3、5…页）/`偶数页`（只盖 2、4、6…页）。
- `seam.pos`：`上`/`下`/`左`/`右`。
- `seam.percent`：骑缝章位置百分比（默认 50）。
- `seam.split`：`auto`（自动按页数）或数字。

### range（盖章范围，pdf-stamp）

- `mode`：`all` 所有页 / `first` 首页 / `last` 尾页 / `custom` 自定义（配 `start`/`end`：`start`=起始页码、`end`=结束页码，含两端，页码按文件实际页序 1 起）。
- `xPct` / `yPct`：盖章位置（页面百分比中心，默认 50/50）。

### watermark（水印）

- `text`：水印文字（必填）。**支持多行**：JSON 的 text 中用 `\n` 换行；对话中用户直接回车换行亦可，程序按行分别渲染并自动按水印框宽度换行。
- `fontName`：字体（默认微软雅黑）。
- `colorArgb`：颜色 ARGB 整数（默认 -2147476961 = 深蓝）。
- `opacity`：透明度 0-100（默认 30）。
- `rotation`：旋转角度（默认 30）。
- `align`：对齐 0 左 / 1 中 / 2 右。
- `letterSpacing` / `lineSpacing`：字距/行距（-150~300）。
- `fontScale`：字号与框高比例（默认 0.8）。
- `fsToS`：**字号/页面短边比例**（默认 0.08，即字号≈短边 8%，横竖页/横竖图片字号一致）。**必须保留此字段**——缺省时旧版按"框高×fontScale"计算会得到约为页面高 48% 的特大字号，水印将超出页面。
- `pos`：位置 `center`（居中）/ `bottom`（底部）/ 或用 `x`/`y`/`w`/`h` 直接指定相对位置（0~1）。

### textStamp（按文字盖章）

- `keyword`：要盖章的文字（必填）。
- `ctxRange`：上下文检索范围（默认 10）。
- `matchMode`：`all` 全部命中 / `any` 任一命中。
- `ignoreSpace`：是否忽略空格（默认 false）。
- `offset.x` / `offset.y`：盖章位置偏移（毫米）。

### output（输出）

- `dpi`：输出清晰度（PDF 默认 150）。
- `mark`：文件名标记（默认 `已处理V`，编号直接接在后面）。
- `pos`：标记位置 0 文件名后 / 1 文件名前。
- `seq`：编号类型 0 数字 / 1 大写字母 / 2 小写字母。
- `pad`：编号位数 1/2/3。
- `ts`：是否插入时间戳（false/true）。
- `tsFormat`：时间戳格式（.NET 日期格式，默认 `yyyyMMdd`，如 `yyyyMMdd_HHmm`）。
- `dir`：自定义输出目录（缺省=源文件夹`已处理`）。

## 四点五、读取软件配置与印章参数（自检用）

运行 `scripts/seal_info.py "<软件文件夹路径>"` → 返回 UTF-8 JSON：`config` = config.ini 全部键值（原样）；`seals[]` = 印章清单 + 每章已保存参数（字段见上，印章参数不填 JSON 时按该章已保存值执行）。**只读不改 config.ini（铁律）**。

## 五、通用规则

- `input`：**仅支持文件夹目录**（单路径或数组=同类型一个 JSON 处理多个文件夹，各输出到自身 `已处理\`），**不支持单文件路径**；软件只扫各文件夹**根目录**（不看子目录）；
- 输出**永不覆盖源文件**；
- 需要按文件粒度处理（部分文件跳过）时，用**临时文件夹方案**：把要处理的文件复制到 `运行组件\智能体调用\智能体调用工作过程文件\临时_任务名\` → 对该临时文件夹执行任务 → 把输出移回源文件夹 `已处理\` → 删除临时文件夹。
