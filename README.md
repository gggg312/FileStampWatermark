# 文件批量盖章与水印工具

Windows 桌面软件：PDF 批量盖章（页面章 / 骑缝章 / 按文字盖章）、PDF 文字水印、图片批量水印，本地处理、所见即所得，支持把批量任务交给 AI 智能体完成。

## 使用说明

### 一、安装与配置

本软件为单文件免安装程序，下载后直接运行即可。首次运行后，会在 EXE 同目录生成一些配置文件，因此建议将 EXE 单独放在一个文件夹中运行，再发送快捷方式到桌面使用，以免误删或误改配置文件。

**首次运行软件后，软件目录结构介绍：**

- 软件主程序（EXE）；
- 《智能体用户使用说明.md》（用户使用智能体调用前必看）；
- WebView2Loader.dll（界面渲染引擎）；
- app_log.log（运行日志：记录本次与上次运行全过程，复现问题后请提供此文件）；
- 「运行组件」文件夹：
  - 「WebUI」：软件界面文件；
  - 「WebView2缓存」：内核缓存；
  - 「印章库」：存储用户导入的印章图片；
  - pdfium.dll（PDF 渲染引擎）、config.ini（软件配置文件）；
  - 「智能体调用」：
    - 《智能体调用手册.md》（供 AI 智能体阅读的使用手册，出厂内容，每次启动软件自动重置为官方版本）；
    - 《补充手册.md》（记录你的使用习惯与成功经验，软件不会覆盖它，由智能体经你确认后写入，可随时查看修改；非初始目录，随智能体调用工作才会生成）；
    - 「智能体调用任务模板」（供 AI 智能体调用的工作任务模板）；
    - 「file-stamp-watermark」（智能体调用技能包文件夹，供支持安装技能的智能体加载使用）；
    - 「智能体调用工作过程文件」（智能体执行任务时产生的任务文件与日志，统一存放于此，可随时根据需要清理；非初始目录，随智能体调用工作才会生成）。

## 二、快速开始

**主要功能介绍：**

1. PDF 文件：页面盖章、盖骑缝章、加水印，带批量处理功能。
亮点功能：随机角度位移与印章渲染，让盖章效果模拟现实盖章的随机性，不再每页完全一致；

2. 图片：加水印，带批量处理功能；

3. 为智能体调用软件，专门在运行组件内加入了《智能体调用手册》，使智能体调用本软件工作更加高效。

**（1）PDF 盖章 / 水印：**

1. 将 PDF 文件或文件夹拖入软件预览区，或点击「选择文件 / 选择文件夹」按钮选取；
2. 选择印章并设置参数，或启用水印功能添加水印框；
3. 在左侧导航选择要用的功能，在控件区调试功能；
4. 使用盖章、批量盖章、水印功能进行操作；在预览区点鼠标右键可以删除印章，也可以鼠标拖动印章调整印章位置；
5. 在预览区确认效果无误后，点击底部「生成结果文件」，输出结果文件，在系统日志内可以看到输出的文件名与目录。

**（2）图片水印：**

1. 将图片或图片文件夹拖入软件预览区，或点击「选择文件 / 选择文件夹」按钮选取；
2. 添加水印框、调整内容与参数；
3. 点击「生成结果文件」，输出带水印的图片，在系统日志内可以看到输出的文件名与目录。

图片模式**仅支持水印功能**，需要盖章请转为 PDF 处理。

## 三、智能体调用

1. 本软件支持把批量任务交给 AI 智能体（如豆包工作任务模式、WorkBuddy 等）处理：你只需把软件文件夹挂载到智能体工作区并说明需求，智能体会自动完成盖章 / 水印并反馈结果，不需要自己操作界面。
2. **第一步（准备工作）**：把本软件文件夹（存放本软件主程序 EXE 的文件夹）挂载到智能体的工作区 / 项目文件夹中；先双击运行一次 EXE（让「运行组件」等文件由程序自动生成到本软件文件夹内），并在软件界面内把印章添加好。
3. **第二步（开始对话）**：阅读本软件文件夹内《智能体用户使用说明.md》，按文件内容做好相应准备工作后，复制文件内的开场白文字发给智能体；智能体自行阅读《智能体调用手册.md》，然后引导你说明需求并执行任务。

## 六、功能详解

### 6.1 印章参数

**功能说明：** 印章的导入、选择、重命名、删除与显示参数设置。

**入口：** 左栏导航 → 印章参数。

**操作步骤：**

1. 点击「选择印章」导入印章图片（仅支持 PNG，建议使用透明背景的图章图片）；
2. 在下拉框中切换当前使用的印章；
3. 调整显示参数；
4. 如需去白，在导航选中「印章参数 → 去白」。

**参数说明：**

- 显示参数：尺寸（单位 mm）、不透明度（百分比）、旋转（单位度）；
- 去白容差：自动去除印章图片的白色背景，容差可调；
- 印章文件下拉框：选项右侧 ✎ 重命名、✕ 删除。

**注意事项：**

- 删除印章需谨慎，删除后需重新导入。

### 6.2 PDF 页面盖章（手动）

**功能说明：** 在预览页面上手动放置印章，所见即所得。

**入口：** 预览区直接操作，无需打开导航。

**操作步骤：**

1. 导入 PDF 文件；
2. 在「印章参数 → 选择印章」中选中要使用的印章；
3. 在预览区左键单击空白处，在当前页盖章；
4. 按住印章可拖动微调位置；
5. 确认效果后点击「生成结果文件」。

**参数说明：**

- 印章尺寸、不透明度、旋转角度在「印章参数」中调整（见 6.1）。

**注意事项：**

- 右键单击印章可删除印章。

### 6.3 骑缝章

**功能说明：** 模拟页面骑缝章效果。

**入口：** 左栏导航 → 印章参数 → 骑缝章设置。

**操作步骤：**

1. 选择骑缝章类型（全部页 / 奇数页 / 偶数页）（默认全部页）；
2. 选择骑缝位置（右 / 左 / 上 / 下）（默认右）；
3. 调整位置百分比（默认 50%）。

**参数说明：**

- 类型：不加 / 全部页（每页都盖）/ 奇数页（只盖 1、3、5…页）/ 偶数页（只盖 2、4、6…页）；
- 位置：右 / 左 / 上 / 下；
- 位置百分比：默认 50%；
- 分割数：默认「自动」按文档页数自动调整，可手动修改数字。

**注意事项：**

- 同一 PDF 内竖向页面与横向页面并存时，软件按现实盖章效果自动换算方向：竖向页骑缝在右 → 横向页骑缝在下（竖右横下、竖下横左、竖左横上、竖上横右）。

### 6.4 指定范围页批量盖章

**功能说明：** 对指定的页码范围内批量盖章。

**入口：** 左栏导航 → 批量盖章 → 指定范围页批量盖章。

**操作步骤：**

1. 输入起始页与结尾页；
2. 点击确定，预览页面跳转至最后一页，在页面上点击，完成本次批量盖章；
3. 预览效果后可点击"撤销放置"按钮取消，对印章点击鼠标右键可选择性删除印章。

**参数说明：**

- 起始页、结尾页：要盖章的页码范围。

**注意事项：**

- 仅对当前文件生效；
- 范围内点击「结束页」自动为每页盖章，翻页限定在范围内。

### 6.5 按文字批量盖章

**功能说明：** 输入"目标文字"（如公司名称），软件自动在页面上搜索"目标文字"的位置并盖章。

**入口：** 左栏导航 → 批量盖章 → 按文字批量盖章。

**操作步骤：**

1. 输入需要盖章的"目标文字"；
2. 设置匹配参数（可选）；
3. 点击「按文字放置印章」进行效果预览；
4. 预览效果后可点击"撤销放置"按钮取消，对印章点击鼠标右键可选择性删除印章。

**参数说明：**

- 附近关键词："目标文字"一定范围内出现"关键词"才符合盖章要求；
- 上下文范围：设定"目标文字"前后多少字内出现"关键词"才符合盖章要求（默认 10 字）；
- 匹配模式：全部关键词 / 任一关键词；
- 中心偏移：调整盖章中心与"目标文字"中心的对齐偏移。

**注意事项：**

- 成功盖章的关键词自动存入搜索历史（近期 10 个），点输入框下拉可查看、可删除；
- 图片型 PDF 没有文字层，不支持此方式；
- 文件夹模式下对文件夹内所有文件生效，单文件模式对当前文件生效。

### 6.6 批处理文件盖章

**功能说明：** 给文件夹内全部 PDF 批量盖章。

**入口：** 左栏导航 → 批量盖章 → 批处理文件盖章。

**操作步骤：**

1. 以文件夹模式导入 PDF 文件夹；
2. 设置页码范围与盖章位置；
3. 点击「批量放置印章」进行效果预览；
4. 预览效果后可点击"撤销放置"按钮取消，对印章点击鼠标右键可选择性删除印章。

**参数说明：**

- 页码范围：所有页 / 首页 / 尾页 / 自定义；
- 盖章位置：X / Y 百分比（以页面左上角为原点）。

**注意事项：**

- 对文件夹内所有文件生效。

### 6.7 随机角度位移

**功能说明：** 盖章时按设定范围随机旋转与位移，模拟手工盖章效果，避免每页印章完全一致。

**入口：** 左上方开关与按钮。

**操作步骤：**

1. 在工具条左侧开启「随机角度位移」开关；
2. 点击旁边的按钮打开参数面板；
3. 调整旋转与位移范围；
4. 正常盖章，效果自动应用。

**参数说明：**

- 旋转角度：随机旋转范围；
- 横向位移、纵向位移：随机位移范围。

**注意事项：**

- 需与「盖章渲染」配合使用效果更佳。

### 6.8 盖章渲染

**功能说明：** 模拟真实盖章的纹理与色调效果，让印章看起来像手工盖的。

**入口：** 左上方开关与按钮。

**操作步骤：**

1. 在工具条左侧开启「盖章渲染」开关；
2. 点击旁边的按钮打开参数面板；
3. 调整参数或使用参数预设；
4. 正常盖章，效果自动应用。

**参数说明：**

- 明暗与纹理：浓淡不均 / 径向压印 / 局部露白；
- 斑点：内部斑点 / 斑点大小；
- 色调与过渡：渐变过渡 / 整体色偏；
- 参数预设 1~4：可保存 / 加载 / 恢复默认。

**注意事项：**

- 调试技巧：导入一个空白 PDF 页面，打开盖章渲染功能，在空白页面上盖几个章子，放大页面到能看清章子细节；在参数弹窗内调整各项参数观察章子变化，直到基本符合需求后保存参数，下次直接加载此参数即可。

### 6.9 文字水印

**功能说明：** 给 PDF 或图片添加水印框，支持多行、自动换行、旋转与透明度调整。

**入口：** 左栏导航「文」→ 添加文字水印。

**操作步骤：**

1. 在左栏导航点击「文」启用文字水印；
2. 点击「添加文字水印」，在当前页添加水印框；
3. 双击框内文字进入编辑，输入水印内容；
4. 调整参数（字体、字号、颜色、透明度等），即时生效；
5. 确认效果后点击「生成结果文件」。

**参数说明：**

- 字体：微软雅黑 / 宋体 / 黑体 / 楷体 / 仿宋；
- 字号、颜色（快捷色板 + 自定义）、透明度、旋转、行距、字间距、对齐（左 / 中 / 右）；
- 水印框操作：双击编辑；文字超出框宽自动换行；框下旋转 / 移动按钮；四角圆点缩放（文字随框自动调整大小）；
- 水印框快捷键：复制：Ctrl+C；粘贴：Ctrl+V；删除：Delete 键；手动换行：Enter 键；
- 预存水印框：对水印框右键，选择保存当前水印框，可将当前水印框内容与参数当做模板进行保存，下个文件可选择直接调用。

**注意事项：**

- 水印模式与盖章模式互斥（PDF 模式）：启用文字水印后，预览区右上角出现模式提示条，水印模式下水印可编辑、不可盖章；盖章模式可以盖章、水印不可编辑。

### 6.10 预览视图与工具条

**功能说明：** 预览区的视图切换与翻页、缩放、跳转操作。

**入口：** 预览区上方悬浮工具条（PDF 与图片共用同一套）。

**视图说明：**

| 视图 | 说明 | 操作 |
| --- | --- | --- |
| 单页 | 一次显示一页 | 鼠标滚轮翻页 |
| 放大 | 页面按比例放大阅读 | 左键按住拖动页面；滚轮上下滚动阅读（滚到底 / 滚到顶自动翻到下一页 / 上一页）；Ctrl + 滚轮缩放 |
| 双页 | 两页并排预览，固定 100% 比例 | 鼠标滚轮翻页 |
| 四页 / 八页 | 多页网格浏览（每行 4 页 / 8 页，向下滚动浏览全部页面） | 双击某页直接切回该页的单页视图 |

**工具条说明：**

- 文件下拉框：切换当前文件 / 图片；
- ◀ ▶ 上 / 下一页（图片模式为上一张 / 下一张）；
- 页码输入框：输入后回车跳转页面；
- － / ＋ 缩小 / 放大（Ctrl + 滚轮也可缩放）；
- 「常驻 / 自动收起」：切换工具条显示方式。

**注意事项：**

- 四页、八页网格视图用于整体查看每页效果（含已放置的印章与水印展示），不能盖章或添加水印，需要编辑时软件会自动切回单页视图；
- 双页视图固定 100% 比例，不可放大缩小；
- 图片模式仅单页 / 放大两种视图。

### 6.11 输出设置

**功能说明：** 输出结果文件的模式、格式、清晰度与命名规则。

**入口：** 左栏导航 → 输出设置。

**操作步骤：**

1. 选择输出模式；
2. 选择输出格式（可多选 PDF / JPG / PNG）；
3. 设置输出 DPI 与文件名后缀。

**参数说明：**

- 输出模式：合并模式（盖章 / 水印直接合入页面内容，合并后文字不可编辑）/ 叠加模式（盖章以可编辑元素浮于页面上）；
- 输出格式：PDF / JPG / PNG 可多选（默认仅 PDF）；选择图片格式时，每个 PDF 输出到一个「源文件名_标记_格式名」文件夹内；
- 输出 DPI：极高 300 / 高 200 / 标准 150 / 低 96 / 极低 72（默认标准），DPI 越大文件越清晰、占用空间越大；
- 文件名后缀：可设置命名文字、编号位置（前 / 后）、递增类型（数字 / 字母）、位数与时间戳；默认「已处理V + 编号」。

**注意事项：**

- 输出 DPI 对合并（栅格化）模式与图片格式输出生效，叠加模式不受影响；
- 图片模式下该设置区自动禁用（图片输出固定为原始图片格式）；
- 同一源文件已存在的输出自动使用 V1、V2、V3 等版本号递增，不覆盖旧结果，例如 1.pdf 输出为 1_已处理V1.pdf；
- 首次启动默认：不加骑缝章、手动点击盖章、合并模式、文字水印关闭。

## 七、常见问题

**Q：如何调整印章尺寸，使其与真实印章一致？**

A：导入一份盖有真实印章的 PDF 作参照，再导入对应的印章 PNG；在「印章参数」中调整尺寸，在参照 PDF 上盖章比对，反复微调直至一致。

**Q：盖章操作，有什么技巧？**

A：对印章点击右键，可以删除印章，批量印章可以根据需要选择性的删除。印章可以鼠标拖动微调位置。

**Q：为什么生成的 PDF 变大了？**

A：DPI 越高文件越大越清晰；「输出 DPI」选标准 150 即可兼顾清晰度与文件大小。

**Q：如何给文件夹内所有文件盖章？**

A：先选择文件夹，再在导航开启「批量盖章 → 批量（批处理文件）」或「按文字批量」，按参数设置后批量处理。

**Q：如何让印章看起来像手工盖的？**

A：开启工具条左侧「随机角度位移」并调节旋转角度与横纵位移，同时开启「盖章渲染」模拟真实纹理与色调，效果更接近手工。

**Q：图片型 PDF 能按文字盖章吗？**

A：不能。图片型 PDF 没有文字层，仅支持手动或批量位置盖章。

**Q：图片能盖印章吗？**

A：不能。图片模式仅支持文字水印，需要盖章请转为 PDF 文件导入。

**Q：印章有白底怎么办？**

A：在左侧导航选中「印章参数 → 去白」，调整容差去除白色背景。

**Q：选了骑缝章，但是页面上看不到，是怎么回事？**

A：骑缝章是按分割数进行分割的，如果文件页数较多，按自动分割会将骑缝章分割的很小，接近于看不到；可以手动将分割数调整为150-200左右。

**Q：水印文字如何换行？如何调整大小？**

A：双击水印框编辑文字，Enter 换行；文字超出框宽也会自动换行。拖动水印框、调整框大小，文字会随之自动调整大小。

**Q：如何快速添加水印框？如何快速添加多个重复的水印框？**

A：制作好水印框后，可以对水印框右键，保存当前水印框，后续就可以直接添加到页面；对水印框可以通过快捷键 Ctrl+C、V，或者鼠标右键复制粘贴水印框，快速添加多个重复的水印框。

**Q：印章旋转后被切角是怎么回事？**

A：部分非圆形印章，或印章在图片上不居中时，旋转时会被切边；建议在图片中给印章四边留空区域大一些，可避免旋转时裁切边缘；留白越大，相同尺寸下章内容显示越小，需自行调大印章尺寸。

**Q：智能体的工作模式是什么样的，工作效果好坏取决于什么？**

A：在智能体工作模式下，本软件仅仅属于智能体的盖章工具，智能体理解了本软件的各种盖章方法，通过智能体与用户对话了解需求，来确定盖章页面、盖章位置等内容，然后智能体调用本软件来实施。具体的工作效果好坏，基本上取决于智能体本身、用户的需求描述等方面，本软件作为一个工具，不参与盖章决策。

**Q：智能体的工作模式比人工使用软件的有什么优点？或者说智能体的工作模式更适合处理什么样的工作？**

A：简单的、少量的文件处理，由人工处理更加方便。如果是重复性的，或者大量需要人工甄别的工作，可以尝试使用智能体处理，例如有 100 份文件，文件内容与页数均不相同，需要在某些特定位置盖章，无法通过按文字盖章识别，需要人工识别具体的盖章位置时：

1. 合同尾页双方公司盖章处、承诺书处、报价书尾页处等本公司名称的位置盖章，在正文内出现的公司名称处不盖章；
2. 某些页面上，两个公司名称离得很近，需要盖章在其中一个公司名称上，而印章不能压到另外一个公司名称。

以上均属于需要人工识别的工作，而印章软件无法做到这些工作，在以上工作量大时，可以尝试给智能体描述清楚需求，让智能体按规则调用盖章软件进行盖章。

**Q：智能体说《智能体调用手册.md》每次启动会重置，我的使用习惯怎么保存？**

A：告诉智能体你的习惯与成功经验，它会经你确认后写入「运行组件\智能体调用\补充手册.md」——软件不会覆盖这个文件，这个文件属于你与智能体交互工作后存留的经验记录，下次同类任务自动沿用。例如各种结合用户自身需求的任务，每个任务完成后，可以由智能体总结经验存放到补充手册内，这样随着用户的使用，智能体每次工作前可以参考同类的完成经验，进而越来越高效。

**Q：智能体执行任务时产生的过程文件放在哪里？**

A：统一放在「运行组件\智能体调用\智能体调用工作过程文件\」目录，可随时查看或清理，不影响软件使用。
